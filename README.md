# 琥珀日记 Amber

每天写一句话，把今天封进一颗琥珀里。

- **琥珀墙**：每条记录是一颗琥珀，按月份排列。琥珀的颜色代表心情：金珀（开心）、蜜蜡（温暖）、血珀（激动）、绿珀（平静）、蓝珀（低落）。
- **连续天数**：记录你连续写了几天。
- **时间胶囊**：写一段话给未来的自己，到了设定的日期才能打开。

## 运行方式

整个应用就是一个文件 `index.html`，不需要安装任何东西。

- **在 Claude 上打开**：作为 Claude Artifact 发布时，日记保存在你账号的私密空间里，只有你自己能看到，换设备也能看到。
- **本地打开**：直接用浏览器打开 `index.html`，日记保存在这台设备的浏览器里（清除浏览器数据会丢失）。
