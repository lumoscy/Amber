# Amber

## 🧩 链动小铺货源增强筛选 · `edge-ldxp-filter/`

链动小铺商家用的 Edge / Chrome 浏览器扩展：拉取货源数据，在本地筛选、排序，计算差价和利润率，并可导出 CSV。基于 [WowJokerH/edge-ldxp-filter](https://github.com/WowJokerH/edge-ldxp-filter) 改进，安装和使用方法见 [目录内的 README](edge-ldxp-filter/README.md)。

## 存档

之前的两个应用封存在分支 [`archive/v1-diary-and-kindred`](https://github.com/lumoscy/Amber/tree/archive/v1-diary-and-kindred) 里：

- 🍯 **琥珀日记**：每天一句话封存成琥珀，外加时间胶囊（`diary/`）
