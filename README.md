# Amber

一些小而实用的单页应用，每个都是一个 HTML 文件，不需要安装任何东西。

## 💬 Kindred · `chat/`

和你自己设定人格的 AI 角色聊天，手机上用起来像聊天 App。

- **自定义人设**：名字、头像、人设、说话风格、开场白
- **多个角色**：自带三个模板（咖啡馆老友 Amber、职业导师老周、橘猫年糕），也可以从零写一个
- **记得聊过的内容**：每次回复都会带上最近 40 条对话
- **回复模式**：「快速」适合闲聊，「用心」适合聊正事
- 回复是边生成边显示的，可以随时停止

作为 Claude Artifact 打开时，页面用你自己的 Claude 账号来生成回复，不需要 API Key；角色和聊天记录保存在你账号的私密空间里，只有你能看到。

## 🍯 琥珀日记 · `diary/`

每天一句话封存成一颗琥珀，还可以给未来的自己埋时间胶囊。
