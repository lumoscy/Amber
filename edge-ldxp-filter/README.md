# 链动小铺货源增强筛选

给链动小铺商家用的 Edge / Chrome 浏览器扩展（Manifest V3，不依赖油猴）。它通过原站接口拉取货源，在浏览器本地筛选、排序，计算差价和利润率，并能导出 CSV。

> **来源**：基于 [WowJokerH/edge-ldxp-filter](https://github.com/WowJokerH/edge-ldxp-filter)（提交 `73bddaf`，版本 1.0.19）修改，原作者 WowJokerH（哇咔咔）。原项目没有声明开源许可证，版权归原作者所有。这里的修改（当前版本 1.2.2）计划以 PR 的形式反馈给原项目。原作者的[视频演示](https://www.bilibili.com/video/BV1kyLb6fEWa/)可以先看一眼。

## 安装

1. 下载并解压本仓库，找到 `edge-ldxp-filter` 文件夹。
2. 打开扩展管理页：Edge 是 `edge://extensions/`，Chrome 是 `chrome://extensions/`。
3. 打开 **开发人员模式**（Chrome 叫 **开发者模式**）。
4. 点 **加载解压缩的扩展**（Chrome 叫 **加载已解压的扩展程序**），选择 `edge-ldxp-filter` 文件夹。

## 开始使用

1. 先登录链动小铺商家后台。扩展从页面的 `localStorage` 读取 `auth-token`，作为 `Merchant-Token` 调用接口，没登录就拉不到数据。
2. 打开 `www.ldxp.cn`、`pay.ldxp.cn` 或 `wzyp.cn` 下的页面，右上角会出现一个可拖动的小胶囊，点它展开面板。
   - 搜开放货源：去 [货源广场](https://www.ldxp.cn/merchant/my_parent/source_square)。
   - 读指定货源商（非公开货源）：去 [对接申请页](https://www.ldxp.cn/merchant/my_parent/apply)，在面板里填货源对接码。
3. 选好条件，点 **开始拉取**。

关掉面板后，点浏览器工具栏上的扩展图标可以重新打开；在其他网站点图标，会直接打开货源广场。

## 功能

### 拉取数据

- **数据来源**：`开放货源搜索` 调用 `/merchantApi/MyParent/searchGoodsList`；`指定货源商` 调用 `/merchantApi/MyParent/parentGoodsList`，需要填货源对接码（`agent_key`）。对接码输入框只在选了指定货源商时出现。
- **拉取页数**：5、10、20、50 页，或 `全部`（拉到没有数据为止，最多 500 页）。顶部有进度条，每拉完一页表格就刷新一次。
- **请求间隔**：在 `更多筛选` 里，默认 1 秒，最小 0.2 秒。第 1 页立即请求，从第 2 页开始等待。
- **去重**：同一商品在不同页重复出现会自动跳过，汇总里会显示跳过了多少条。
- 拉取中再点一次按钮（此时显示 **停止拉取**）可以中止。关键词框里按回车，如果还没有数据会直接开始拉取。

### 筛选、排序和导出

- 面板第一行决定拉什么（数据来源、关键词、商品类型、拉取页数），第二行是常用筛选（成本价区间、库存、对接状态、排序）。上架状态、分类、商家和请求间隔收在 `更多筛选` 里。
- 筛选条件改了立即生效，不用重新拉取。关键词、分类和商家名都不区分大小写。
- 库存未知的商品（通常是不限库存）算作有库存，不会出现在 `仅无库存` 里。
- 表格有 `差价`（售价 − 成本价）和 `利润率`（差价 ÷ 成本价）两列。点售价、成本价、差价、利润率、库存、销量的表头可以排序，依次切换降序、升序、默认。
- 每页显示 10 / 20 / 30 / 50 条，默认 10 条。
- **导出 CSV**：导出筛选后的全部结果，带 BOM，Excel 直接打开不乱码。

### 对接和详情

- 未对接的商品点 `对接` 会打开对接配置弹窗（复用原站接口），确认后调用 `/merchantApi/MyParent/connectGoods`。已对接的商品显示 `查看`，跳到原站返回的已对接商品链接。
- 点 `详情` 在弹窗里看商品详情。
- 商品图来自商品描述里的第一张图片，没有就用商家头像。
- 旧店铺域名会自动换成新的：`https://pay.ldxp.cn/shop/ldxp` → `https://wzyp.cn/shop/ldxp`。

### 面板

- 标题栏可以拖动，右下角手柄可以调大小。右上角三个按钮：最小化成悬浮图标、最大化（铺满窗口，再点或双击标题栏还原）、关闭。
- 最小化后的悬浮图标可以拖动，单击恢复面板。
- 浏览器窗口变小时，面板会自动缩小并留在屏幕内。
- 筛选条件、面板大小和小胶囊位置保存在本机浏览器里，下次自动恢复。数据来源仍按当前页面自动判断；网址里带的货源对接码优先于保存的值。
- 面板底栏固定放着原作者的卡网链接和感谢小纸条。

## 遇到限流怎么办

平台 CDN 限流时返回 `HTTP 403`，响应头带 `X-Tengine-Error: denied by http_ratelimit`。扩展识别到后会：

- 依次等 15、30、60 秒重试，最多 3 次，已拉到的数据会保留；
- 把后面几页的请求间隔自动翻倍（最多 10 秒）。

网络错误、5xx 和“请求频繁”之类的提示也会重试，从 2 秒起步。其他 403 会提示你检查登录状态，并确认是在 `www.ldxp.cn` 商家后台页面使用。

如果经常被限流：

- 把请求间隔调到 3 到 5 秒；
- 用代理（VPN）时，出口 IP 常和很多人共用，更容易触发限流，建议在代理规则里让 `ldxp.cn` 直连。

## 开发

### 接口字段变了改哪里

扩展按真实接口字段取值：商品名 `name` / `title`，分类 `category.name` / `category_name`，商家 `user.nickname` / `nickname` / `shop_name`，库存 `stock_count`，对接状态 `child`，上架状态 `status`，价格 `price` / `cost_price`。字段变了的话，优先改 `content.js` 里这几个函数：

- `buildRequestBody`
- `normalizeList`
- `getProductTitle`
- `getMerchant`
- `getCostPrice`
- `getConnectedLabel`
